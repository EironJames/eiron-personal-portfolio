HOW TO OPEN
-----------
1. Extract the ZIP file if you received this project as a ZIP.
2. Keep index.html, style.css, and the images folder together in the same project folder.
3. Open index.html in a modern web browser (Chrome, Edge, Firefox, or Safari).
4. On a phone, transfer the complete folder to the device and open index.html with a browser,
   or upload the folder to a static web host.

IMPORTANT FILE RULES
--------------------
- Do not move the images out of the images folder unless you also update the image paths in HTML.
- Do not rename style.css unless you update the stylesheet link in the HTML head.
- The portfolio uses one HTML page with separate sections: Home, About, Skills,
  Certificates, Projects, Hobbies, and Contact. The navigation links jump to those sections.
- The contact action uses a mailto: link. It opens the visitor's configured email application;
  it does not send a message through a website server.
- The Projects section is intentionally an honest placeholder because no actual project
  files were supplied. Replace it only when you have genuine work to show.
- The certificate cards open a larger preview. The four image files are the exact images
  supplied for this project.
- The Google Fonts connection is optional. If the device is offline, fallback fonts are used.

EDITING
-------
Use a text editor such as Visual Studio Code or Notepad.
Edit text in index.html. Edit colors, spacing, fonts, and layout in style.css.
Save the files, then refresh the browser to see changes.
